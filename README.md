# Pre-Entrega 6 -- Simulador de venta de empanadas

## Cambios incorporados para cumplir consigna de entrega 

FILTER: obtiene los productos con stock disponible para mostrar y tomar pedidos.
REDUCE : calcula el importe total de la compra.
FILTER : identifica los productos vendidos.
MAP : prepara el detalle del ticket con nombre, cantidad, precio unitario y subtotal.
FIND : permite consultar un gusto para la próxima visita , para facilitar esto se 
cambiaron los nombres de las empanadas a una sola palabra.
